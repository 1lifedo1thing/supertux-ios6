# SuperTux for iOS 6

A port of SuperTux 0.7.0 for iOS 6.
It uses as base the Android build, supporting mobile controls

This proyect was developed using ChatGPT Codex.

## Download and installation

1. Download the .ipa or .deb in the 
   [releases page](https://github.com/Alsainz1/supertux-ios6/releases).
2. Install it via your prefered App Manager
4. Launch the port and play!

## Building

See [the iOS build instructions](ios/README.md).
